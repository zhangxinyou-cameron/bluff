========================================
  德州扑克·公网联机版 使用说明
========================================

【房主操作】
1. 双击「start.bat」
   每次启动都需要输入本次网站访问密码（8—128个字符，输入时不显示）。
   输入一次即可；可自行使用与上次相同或不同的密码，不会自动沿用旧密码。
2. 等几秒，窗口会显示：
     你自己访问:  http://localhost:3000
     🌐 公网地址:  https://xxxx.trycloudflare.com
3. 自己浏览器打开 http://localhost:3000，先输入访问密码
4. 点「创建房间」，得到6位房间号；可在开局前设置“允许买入”
5. 把【公网地址 + 房间号】发给朋友，并通过私密方式告知访问密码

【朋友加入】
1. 不管朋友在哪（4G/不同WiFi都行）
2. 浏览器直接打开房主发的公网地址
   例如 https://xxxx.trycloudflare.com
3. 先输入与房主相同的访问密码，再点「加入朋友的牌局」，输入6位房间号
   打开带 #room=房间号 的分享链接，会在密码验证通过后自动入房。
4. 点准备，等房主开始

【重要】
- 从Git仓库启动时，公网工具需另行放置：将cloudflared.exe复制到实际启动目录（本机为E:\bluff），或加入系统PATH，或用CLOUDFLARED_PATH指定完整路径。出现“未找到cloudflared”时，本地服务已启动，但尚无公网地址；补齐后重启服务器
- 未验证密码时只能看到访问验证页，游戏网页、音频和WebSocket连接均被服务器拦截
- 本次密码只在服务器内存中保留随机盐和scrypt摘要，不写入磁盘；旧 data/access.json 已不参与启动
- 登录有效期12小时，重启服务器后所有人都需要重新验证；页面右上角“退出”可立即注销
- 公网请使用窗口提供的 https 地址，密码和游戏通信通过Cloudflare的HTTPS/WSS传输
- 公网地址每次启动都会变，重新启动后要重新发给朋友
- 朋友打开地址可能需要等10秒（Cloudflare首次加载）
- 游戏期间不要关闭黑色服务器窗口
- 支持2-8人（真人与人机合计最多8人），空位可以让人机代替
- 手机、电脑都能玩，微信里直接打开也行

【界面与声音】
- 房主开局前可在房间设置选择“是否显示胜率”（默认显示），对全桌统一生效；关闭后隐藏概率数值并跳过界面胜率计算，仍显示自己的手牌和当前牌型。等待页可查看所选规则，开局后固定，刷新与下一手保留
- 开局后自动定位到一屏牌桌工作区：牌桌、胜率、回合倒计时、下注操作及聊天同时可见；桌面为牌桌与聊天双栏，手机为上下紧凑布局
- 银行、牌制、玩家管理、音乐和房间设置在牌桌上方，向上滚动可查看；聊天记录在栏内独立滚动
- 首页昵称下方或牌桌上方“头像”可选择黑桃、狐狸、熊猫、猫咪、狮子、猫头鹰、兔子、机器人；全桌同步显示，同一浏览器记住选择，刷新/重进保留
- 所有人使用相同的固定座位视图：上排从左到右，再沿右侧到下排从右到左；自己的座位高亮并标“你”，行动按这个顺时针顺序跳过弃牌、全押和旁观者
- 加注快捷项为半池、¾池、满池、双倍底池，按钮同时显示“加注至”的本轮总额。面对下注先计算跟注后的底池，再按比例加注；不足最小加注或超过筹码时自动按合法边界调整，仍支持手输任意合法数额
- 首次操作后播放三首原创慢爵士：《午夜河岸》72 BPM、《雨后慢拍》68 BPM、《窗边月色》74 BPM
- 三首自动轮播并柔和交叉淡入淡出；点“调音→下一首”可主动换曲，后台标签页暂停背景音乐
- 页面右上角可分别开关音乐和音效，点“调音”可分别调节音量，设置会自动保存
- 音乐和6类按钮音效均由Python合成，文件已包含，无需玩家安装Python
- 按钮音效降低两个八度，增添柔和低频和缓入缓出，削弱尖锐高频
- 音乐素材峰值约 -7.54 dBFS，音效素材峰值约 -15.92 dBFS，播放端还有并发限制、压缩和限幅
- 音乐、按钮音效与可选语言包共用压缩与限幅，限制音频叠加峰值

【经典语言包与互动】
- 互动面板使用与牌桌统一的深绿暖金样式，分为“送个心意 / 说句话 / 看牌申请”；礼物为插画卡片，发送后立即关闭面板以观看动画，成功或频率限制会用屏幕提示告知
- 实时麦克风、语音采集和中继功能已移除
- 点击“语言包·表情互动”或玩家卡片，选择语言包发送，例如“快点吧，我等到花儿都谢了”；文字显示在聊天和玩家气泡中
- 在互动面板选择对象，可扔番茄、送咖啡、送花或碰杯；这些为免费动画，不扣筹码，发送有频率限制
- 编辑 public/table-packs.json 可增加或修改短语；音频文件放在 public/audio/packs/，把对应 audio 字段改为 /audio/packs/文件名.wav（也支持MP3/OGG）
- 音频文件每条不超过15秒、8MB；文件名仅用英文字母、数字、下划线、短横线，可用子目录；修改后重启并刷新网页
- 尚未配置音频时文字照常可用。语言包跟随音效开关与音量、后台静音，并自动压低素材峰值和限制叠加播放。接口详见 public/audio/packs/README.txt

【原位恢复与房主踢人】
- 点击“暂时离桌”或等待页“离开”只会暂离，保留原席位、筹码和欠款30分钟；同一浏览器再次输入原房间号可回到原位，关标签页后也可重新加入
- 恢复凭据保存在本机浏览器，不依赖昵称；换设备、无痕浏览、清除网站存储或席位过期后不能恢复
- 房主在“玩家管理”或玩家卡片的互动面板选择玩家，点击“踢出所选玩家”。房客无此权限，房主不能踢出自己
- 被踢出的玩家会立即断开并返回加入界面，不自动重连；点击“重新加入房间”或同一浏览器再次输入原房间号，可用新的单次凭据回到原席位，保留筹码、贷款和头像。刷新被踢后的页面不会自动入房
- 正在进行的手被踢出后保持原弃牌/全押状态，不会恢复已弃手牌的争池资格；下一手正常参与。开局前被踢而原位仍保留时，可重进后先旁观、下一手加入；原空位若已由新人占用，等待室可重新加入分配新位，已开局则需等待新房间
- 踢出正在行动的普通玩家按退桌弃牌处理；已经全押者保留本手应得的结算资格，账户和未还贷款仍计入最后排名
- 房主“暂时离桌”不会关闭房间；主动点击“关闭房间”或服务器重启才会结束房间，长时间无人在线的房间自动清理

【定向看牌与自愿小费】
- 每人可点击牌桌上方“看牌门槛”，开启“达到门槛时自动同意”并设置最低小费；默认手动，0表示免费合资格申请也自动同意。此设置对全桌公开：打开某玩家的互动面板即可看到其门槛
- 小费达到或超过目标门槛直接定向亮牌，无需目标弹窗确认；低于门槛或目标关闭自动同意时，继续10秒手动确认。更改仅影响之后的新申请，已有等待申请保持手动；当前房间内刷新、重连和下一手保留设置，新房间默认手动
- 本手已弃牌的玩家，以及淘汰或无筹码且未参与本手的观战者，可在目标玩家卡片/互动面板申请观看其底牌；无筹码时小费填0，其余可填写自愿小费（可为0）
- 需要手动确认时，目标玩家收到居中弹窗，显示申请人、小费和10秒倒计时，可同意或婉拒；超时失效，按Esc也按婉拒处理。多个申请依次提示，各自仍按原10秒期限计算；未经手动同意或预设门槛自动授权不会亮牌或扣款
- 同意后仅向指定申请者发送牌面，其他玩家及聊天/导出的公共记录不会收到这些未公开底牌；授权仅本手有效
- 目标必须为在线且本手有牌的真人。正在争池（含已全押但未弃牌）、已离桌或过期请求不能申请，伪造他人同意无效
- 正在进行的手，小费在本手结算后转账，避免改变下注筹码；手间同意则立即转账，撤回双方对下一手的确认。多份小费承诺不得超过申请者可用筹码
- 小费单独记入整场记录，单手牌局盈亏保持扑克结算值，最终净筹码排名包含已支付/收到的小费；整场结算后不能再改账户

【全押后发两次牌】
- 房主开局前可设置“跑马发牌间隔”0至3秒，默认3秒；先开翻牌三张，再依次开转牌、河牌，每个阶段及最后看牌停顿均按所选间隔。发两次时组间也保留同样停顿，共用已公开牌，不重新开已公开部分；刷新可继续当前进度
- 至少两人争池、公共牌未发完且已经没有后续下注时，自动出现发牌协商窗口；已经发到河牌或仍有玩家需要下注时不能协商
- 所有仍争池的玩家都明确同意才会发两次；任意一人选择发一次、争池者离线，或20秒内未完成同意，则正常发一次。人机默认同意，已弃牌者不参与
- 保留已经公开的公共牌，使用同一副剩余牌依次补完两组牌，不重新洗牌、不重复抽到新牌
- 每个主池和边池都各自分成两份，分别按两组牌决定赢家；不能争某个边池的玩家不会得到它。奇数筹码先给第一组，每组平局余数按按钮左侧顺序分配
- 结算页显示两组牌和逐池逐组分配；房主在协商时申请结束买入场，也会正常发完、结算当前底池后才公布整场排名
- 本好友游戏允许在标准/短牌及买入/淘汰模式使用此功能。规则参考：https://www.pokerstars.uk/help/articles/run-it-twice-new/

【牌局规则与联机】
- 其他人全部弃牌时，赢家默认不向其他玩家亮底牌；赢家本人可在结算页选择“向全桌亮牌”或“隐藏牌”，下一手重置。正常比牌时按原规则展示摊牌玩家底牌
- 每一轮下注结束并进入新一轮时，玩家行动框会清空上一轮操作，重新显示“尚未行动”；中央提示也只显示当前轮次。弃牌、全押等本手状态仍保留，整局历史可在聊天记录栏查看或导出
- 每局结算后，所有在线真人（含房主及继续旁观的玩家）必须点“确认下一局”，全部确认后才会发牌
- 结算页显示已确认人数及每人的状态；人机自动确认，断线玩家不计入确认人数，旧局/重复确认无效
- 只有轮到自己的玩家可以操作；过期、重复、越序和不合法的下注会被拒绝
- 支持不同筹码量全押的主池/边池结算，未被跟注的部分会退回，平局不会丢失余数筹码
- 结算逐池显示每位玩家实际分得的金额；普通弃牌留下的下注不会被误标成额外边池
- 淘汰赛最终排名按出局先后排序：后出局者靠前，同局出局按本局起始筹码，相同则并列；房客等待时显示“等待房主公布排名”
- 全押和淘汰玩家会自动跳过；无需再下注时自动发完公共牌并结算
- 牌局由Node服务器运行，房主或房客手机进入后台不会停止服务器的牌局、人机和计时器
- 临时断线保留席位30分钟；原标签页刷新、网络恢复或从后台返回会自动重连，同步原手牌、账户与记录
- 在线行动通常限时60秒；当前行动人断线后最多再等30秒，到时可过牌则自动过牌，否则自动弃牌；已全押资格保留
- 主动离开默认暂离并保留席位；已开始的牌局拒绝陌生新玩家，允许原席位恢复或被踢玩家凭单次重进凭据返回
- 默认自动牌制：每手实际在线且有筹码的参与人数2-4人用短牌，5-8人用标准；本手中途断线或弃牌不改变规则
- 房主可在开局前或手间切换“自动人数 / 36张短牌 / 52张标准”，下一手生效；手间切换会撤回全体下一手确认，重新确认后才开局
- 短牌为36张（6到A），同花大于葫芦、顺子大于三条，A6789为最小顺子；底注和盲注可独立于牌制选择
- “1倍底注金额”决定完整盲注和全员底注的基数，半倍为其一半；牌桌及记录明确显示本手实际规则与投入金额
- 短牌版本参考：https://www.pokerstars.com/poker/games/six-plus/
- 多客户端多轮验证结果见 tests/验证报告.md

【底注选择与标准位置】
- 开局前在房间设置，或手间在牌桌上方“底注规则”选择；只有房主可改，下一手生效，切换后所有在线玩家重新确认
- 默认“随牌制”保留原行为：短牌全员底注＋庄家额外一份，标准牌采用标准大小盲
- “标准：SB半倍 / BB1倍”：庄家左手第一位为SB付半倍，再下一位为BB付1倍，其他人不付底注；例如基数20时SB付10，BB付20。翻前从BB后第一位开始，BB保留最后操作权；翻后从庄家左手第一位开始
- 两人标准桌庄家兼任SB，翻前庄家先行动，翻后BB先行动
- 6人标准桌翻前顺序：UTG → HJ → CO → BTN → SB → BB；不使用LJ
- 8人标准桌翻前顺序：UTG → UTG+1 → LJ → HJ → CO → BTN → SB → BB；房间上限仍为8人
- 位置随实际参与人数自动调整，在手牌中固定，庄位轮转后下一手重算；空位、未参与者被跳过，弃牌和全押者不再行动
- 玩家卡片标注位置简称，上方“本桌位置与行动顺序”可展开查看每个座位的翻前、翻后顺序
- “全员底注＋庄家盲注”可用于短牌或标准牌：每人一份底注，庄家再付一份盲注，翻前从庄家左手第一位开始；此模式不使用SB/BB名称，按BTN、BTN+1等距离标注
- “自定义：下家1倍 / 再半倍”按先前要求：庄家左手第一位付1倍（BB）、第二位付半倍（SB），其他人不付；翻前从BB后第一位开始。此为自定义顺序，与标准位置制分别标明
- 盲注筹码不足时只投入剩余筹码，全押、主边池和筹码守恒仍正常处理

【过程提示与异常恢复】
- 加注滑条按本局小盲的整数倍递增（小盲10时每格10）；起止点向合法倍数收拢，不低于最小加注、不超筹码。含零头的金额可手输，或在加注面板点击“全押”选择全部筹码；没有合法整倍数时滑条禁用，仍可手输合法金额
- 固定发手牌过场约1.8秒，正常街间过场约1.2秒；全押跑马默认按3秒间隔分段开牌，最后再停3秒，普通操作后留0.9秒，人机另留思考时间；服务器同步锁定操作
- 牌桌显示最近行动，玩家名字旁持续保留其本手最近一次跟注/加注/弃牌标记；轮到自己时有金色提示、大数字倒计时、进度条和轻音效，最后10秒加强提示
- 新回合在屏幕中央短暂显示“轮到你了”、位置及剩余秒数，约1.65秒自动消失，不阻挡点击；互动面板打开时仍可显示，聊天和重复同步不会反复弹出
- 加注可选半池／¾池／满池／双池、3倍／4倍当前下注，也可用数字输入和滑杆指定任意合法整数；界面显示本次完整加注属于几-BET，翻前首次加注为2-BET、再加注为3-BET，再次为4-BET；短全押不增加完整加注层级。所有金额受最小加注、筹码及加注权限制
- 牌桌下方记录栏保留整场公共行动、公共牌、主边池分配、银行和聊天，可筛选、加载更早记录和导出；不记录他人未公开底牌
- 心跳检测无响应后重建连接，迟迟未收到操作回执会先核对最新状态，避免重复下注或重复贷款；“重新同步”可手动恢复
- 服务器检测行动顺序并校正，筹码账目异常会暂停操作并明确提示，避免错误继续扩散
- 席位和牌局只保存在当前服务器内存；重启服务器或服务器电脑休眠/断网期间无法继续服务，重新开服需创建新房间

【概率与策略人机】
- 人机按自己的底牌、公开公共牌、位置、筹码和公开下注记录决策；不读取对手底牌、实际牌堆顺序或定向看牌授权
- 使用胜率抽样估计，河牌单挑时枚举剩余所有合法对手组合；标准牌与短牌分别按各自牌型大小计算，平分底池按实际份额计入
- 翻前结合位置与起手牌选择开池、跟注或再加注；尚未行动的所有人不会一律当作已经入池全押，已入池玩家的公开行动会影响对手范围估计
- 跟注同时考虑胜率、需要支付的筹码、底池赔率和风险；短筹码只按自己有资格争夺的底池计算赔率，弱牌不再固定大比例跟到底
- 强牌主要做价值下注，也会少量过牌；中等牌会控制底池或做较小的价值下注，下注金额结合底池、筹码深度和对手可跟注筹码
- 同花/顺子听牌可做半诈唬，后位可低频偷盲，干燥牌面上可做持续下注；纯诈唬和诈唬加注均为受条件限制的混合决策
- 多人底池降低诈唬频率，争池对手已全押时不做以逼其弃牌为目的的诈唬；免费过牌时不会无故弃牌
- 最小加注、加注权、短全押和筹码上限仍由统一规则引擎校验；人机思考时间保留，内部胜率和诈唬意图不向玩家或公共聊天记录发送
- 这是基于概率估计与常规策略的娱乐型人机，不是完整GTO求解器；多轮验证见 tests/ai-simulation-report.json 和 tests/ai-browser-report.json

【允许买入 · 银行无限场】
- 房主可在开局前设置“每手贷款限额”和“总贷款限额”：按每位玩家分别计算，可选常用值或输入任意非负整数，0表示禁止借入，选“无限”或清空表示不限。规则开局后固定，银行会显示当前限额和剩余额度
- 每手限额限制每手结算后的累计借入，多次借款合并计算；还款不恢复本手额度，进入下一手后重新计算。总贷款限额限制未还本金，偿还本金会释放总额度。两项同时生效，初始筹码不占贷款额度
- 房主在开局前将“允许买入”改为“是 · 银行无限场”，所有玩家都能在等待页看到本场规则；开局后不能更改
- 本模式不执行破产淘汰，也不按“最少剩余”自动结束，只能由房主点击“结算整局”结束
- 筹码归零仍保留座位，可确认下一手观战，或在手间进入银行买入后重新参与；下一手至少需要两名有筹码的玩家
- 页面上方“银行”查看现有筹码、未还贷款、净筹码及最近记录；贷款买入增加等额筹码和欠款，还款扣减等额筹码和欠款，均无利息
- 只能在每手结算后借还款，进行中的手仅可查账户，避免中途改变下注筹码；还款不能超过现有筹码或未还贷款
- 借还款会撤回该玩家对下一手的确认，需重新确认；其他玩家已确认的状态保留
- 人机筹码归零时会按相同限额自动贷款，额度不足则只借剩余额度，0额度不借；贷款也纳入人机最终账户
- 房主在手间点击“结算整局”立即公布排名；在一手进行中点击则打完本手再结算，不会丢弃底池
- 最终按“现有筹码 − 未还贷款 = 净筹码”排序，含已退桌玩家；净筹码相同并列，净收益还会减去初始筹码
- 借款不是赢钱，还款也不是输钱：单手盈亏保持该手真实结算值，最终另行展示筹码、欠款、累计借还款和净收益
- 重复、过期、伪造他人座位或超出安全整数范围的银行操作均有校验；本功能仅处理虚拟游戏筹码
- 买入与银行多轮检测原始数据：tests/bank-report.json

【常见问题】
- 更新文件后：关闭旧服务器窗口，重新双击 start.bat，房主和朋友都刷新网页后重新进房
- 显示“房间不存在或房主已离线”？确认房主已创建房间，并使用本次启动的公网地址和房间号
- 准备按钮需要等“已连接房间”后才可点击，点击后会显示“已准备，等待房主开始游戏”
- 朋友打不开？等10秒刷新，Cloudflare首次连接较慢
- 地址打不开？确认服务器窗口还开着
- 想要固定地址？需要注册Cloudflare账号配置（较复杂）
