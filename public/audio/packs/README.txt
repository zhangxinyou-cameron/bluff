经典语言包文件接口

1. 把有权使用的 WAV、MP3 或 OGG 文件放在本目录，例如 hurry.wav。
2. 编辑 public/table-packs.json，把对应项的 audio 从 null 改为 "/audio/packs/hurry.wav"。
3. 保留已有 id；text 为按钮和聊天显示的内容，可自行修改。也可增加唯一 id 的新条目。
4. 重启服务器，玩家刷新网页。文字始终可用，未配置音频不会报错。

文件名仅用英文字母、数字、下划线或短横线，可用子目录。
每条不超过15秒、8MB。客户端自动把峰值压至0.35以内，并经过统一压缩、限幅和并发限制。
语言包跟随“音效”开关与音量；页面在后台时不播放，不使用麦克风。
不要在文件中加入外部网址。所有语言包同样受网站密码保护。
